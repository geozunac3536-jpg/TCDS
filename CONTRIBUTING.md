# Contribuyendo a TCDS

## Principio Fundamental
Todo se deduce. Nada se ajusta. Todo se verifica.

## Reglas
1. Sin parametros libres - todo valor debe deducirse algebraicamente
2. Sin entidades inventadas
3. Cierre exacto: H(z=0)=73.04 | H(z->inf)=67.36
4. Todo cambio debe preservar el Hash Maestro o justificar su alteracion
5. Delta H0 debe ser positiva

## Proceso
1. Fork -> rama develop
2. Ejecutar validacion
3. Pull Request con descripcion detallada
